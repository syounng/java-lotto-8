## 🍀 프로젝트 소개

-------
### **[ 로또 발매기 ]**

사용자가 입력한 금액만큼 로또를 자동으로 발행하고, 당첨 번호와 비교해 등수 및 수익률을 계산해주는 프로그램입니다.



## 🚀 주요 기능 목록

-------
### 1. 콘솔 입력
- [x] 로또 구입 금액
  - [x] 숫자가 아니면 예외처리
  - [x] 음수이면 예외처리
  - [x] 1000원으로 나누어 떨어지지 않으면 예외처리
- [x] 당첨 번호
  - [x] 쉼표(,) 기준으로 구분
  - [x] 쉼표(,)가 존재하지 않으면 예외처리
  - [x] 쉼표(,)가 5개가 아니면 예외처리
  - [x] 쉼표(,)가 연달아 2개 이상 입력되면 예외처리
- [x] 보너스 번호
  - [x] 숫자가 아니면 예외처리
  - [x] 1~45 사이의 정수가 아니면 예외처리


### 2. 로또 번호
  - [x] 숫자 범위 1~45
  - [x] 중복되지 않는 숫자 6개
  - [x] 예외처리
    - [x] 숫자가 해당 범위에서 벗어나는 경우
    - [x] 숫자가 하나라도 중복되는 경우
    - [x] 숫자가 6개 보다 적거나 많은 경우


### 3. 로또 발행
- [x] 구입 금액에 맞는 개수의 로또 발행
  - [x] 로또 하나 당 랜덤한 숫자 6개 선정
  - [x] 랜덤한 숫자는 1~45
- [x] 발행된 로또 번호 출력
  - [x] 숫자가 오름차순으로 정렬되어야 함


### 4. 당첨 여부 판단
  - [x] 당첨 통계 출력하기
    - [x] WinningNumber에 저장된 값과 Lottos의 각 Lotto에 저장된 값을 비교
      - [x] 비교 책임은 Lottos에게 부여 (Lotto객체를 순회하며 관리하는 역할을 하는 객체이므로)
      - [x] Lottos는 Rank.of(matchCount, hasBonus)을 사용하여 Lotto의 등수를 판단

    
### 5. 수익률 계산
  - [x] 수익률(%) = (총 당첨금 / 구입 금액) * 100
