# java-lotto-precourse

## 프로젝트 소개


## 주요 기능 목록

- [ ] 로또 번호
  - [ ] 숫자 범위 1~45
  - [ ] 중복되지 않는 숫자 6개
  - [ ] 보너스 번호 1개
  - [ ] 예외처리
    - [ ] 숫자가 해당 범위에서 벗어나는 경우
    - [ ] 문자가 포함되어있는 경우
    - [ ] 숫자가 하나라도 중복되는 경우
    - [ ] 숫자가 6개 보다 적거나 많은 경우


- [ ] 당첨 여부 판단
    - [ ] 숫자 일치 개수 구하기
    - [ ] 숫자 일치 개수에 따라 당첨 내역 변경
      - [ ] 당첨된 등수의 카운트 1 올리기


- [ ] 수익률 계산
  - [ ] 수익률(%) = (총 당첨금 / 구입 금액) * 100


- [ ] 로또 발행
  - [ ] 구입 금액에 맞는 개수의 로또 발행
    - [ ] 로또 하나 당 랜덤한 숫자 6개 선정
    - [ ] 랜덤한 숫자는 1~45
  - [ ] 발행된 로또 번호 출력
    - [ ] 숫자가 오름차순으로 정렬되어야 함


- [ ] 입력
  - [ ] 로또 구입 금액
    - [ ] 1000원으로 나누어 떨어지지 않으면 예외처리
  - [ ] 당첨 번호
    - [ ] 쉼표(,) 기준으로 구분
    - [ ] 쉼표(,)가 존재하지 않으면 예외처리
    - [ ] 쉼표(,)가 5개가 아니면 예외처리
    - [ ] 쉼표(,)가 연달아 2개 이상 입력되면 예외처리
  - [ ] 보너스 번호
    - [ ] 1~45 사이의 정수가 아니면 예외처리
